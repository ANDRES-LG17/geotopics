# 40 — Livrables : ce qui se regarde

```
40-livrables/

```

Une image qui finit dans l'entrée passe ensuite dans `public/covers/`,
redimensionnée pour le web. L'original pleine résolution reste ici.

Toute carte destinée à être lue hors du site porte les mentions obligatoires :
titre, échelle, nord, source et millésime, attribution exigée par la licence
(voir `SOURCES.md`).
